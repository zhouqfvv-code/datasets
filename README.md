# Medical Image Segmentation Benchmark Data

## Overview

This collection organizes third-party datasets for retinal vessel segmentation
and gastrointestinal polyp segmentation, in connection with the manuscript:

**Beyond Hierarchies: A Novel Decoding Paradigm for Medical Image Segmentation**

The datasets are DRIVE, CHASE_DB1, STARE, HRF, IOSTAR, LES-AV, Kvasir-SEG,
and CVC-ClinicDB. The dataset creators retain their respective rights and
attribution. This collection is not a newly collected clinical dataset and is
not an official release from the original providers.
